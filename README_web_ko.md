# 고객 방문 메모 웹 버전

1. `customer_visit_memo_web.py`와 기존 `customer_visits.db`를 같은 폴더에 둡니다.
2. `start_customer_visit_memo_web.bat`를 더블클릭합니다.
3. 브라우저에서 `http://127.0.0.1:8765`가 자동으로 열립니다.
4. 종료하려면 검은색 실행 창에서 `Ctrl+C`를 누르거나 창을 닫습니다.

Python 3만 필요하며 외부 패키지는 사용하지 않습니다. 기존 데스크톱 버전과 같은 데이터베이스 구조 및 SE/AE 저장 형식을 사용합니다. 실제 데이터로 시험하기 전에 `customer_visits.db`를 백업하십시오.

이 버전은 현재 PC에서 한 명이 사용하는 로컬 브라우저용입니다. 다른 사람과 네트워크로 공유하거나 인터넷에 공개하도록 설계되지 않았습니다.
